# 윈도우 재설치 후 한글 입력 보정 복원

이 ZIP은 한 노트북에서 확인한 특정 한글 자모 분리 현상을 막는 보정 프로그램의 복원 패키지입니다. Windows 11 x64용이며, 별도 다운로드나 관리자 권한 없이 현재 사용자에게 설치합니다.

## 재설치 전에

**ZIP을 USB·외장 저장장치 또는 클라우드에 복사해 두세요. C:의 바탕화면·다운로드·문서 폴더에만 두면 윈도우를 밀 때 함께 지워질 수 있습니다.** GitHub에서 ZIP을 다시 내려받을 수도 있지만, 설치 전 외부 사본을 보관해 두면 오프라인에서도 복원할 수 있습니다.

ZIP 안에는 실행 파일, 전체 소스, 설치·제거 스크립트, 검사 페이지, 검증 기록이 있습니다. 예전 사용자 이름이나 Codex 설치는 필요하지 않습니다. 예전 레지스트리 백업을 새 윈도우에 가져올 필요도 없습니다.

## 재설치 후 순서

1. 보정을 설치하기 전에 메모장에서 `소프트웨어 테스트 키보드 발생`을 3~5번 직접 입력합니다. 정상이라면 이 보정은 설치하지 않아도 됩니다.
2. 드라이버와 평소 쓰는 프로그램을 설치하면서 한글을 가끔 확인합니다. 어느 설치 직후 증상이 시작되는지 기록하면 원인을 좁힐 수 있습니다. 재설치만으로 문제가 없어질 수도 있지만, 같은 원인 프로그램·드라이버 또는 장치 문제가 남으면 재발할 수 있습니다.
3. 같은 자모 분리가 재발하면 ZIP 전체를 로컬 폴더에 **모두 압축 해제**합니다. ZIP 안에서 직접 실행하지 마세요.
4. 압축을 푼 폴더의 **`install.cmd`를 더블클릭**합니다. 관리자 권한으로 실행하지 않습니다.
5. 설치가 성공하면 바로 보정이 실행되고 다음 Windows 로그인에도 자동 실행됩니다. 같은 예문을 다시 직접 입력해 확인하세요.

설치 위치는 `%LOCALAPPDATA%\KoreanInputGuard`입니다. 현재 사용자 시작프로그램 폴더에 `한글 입력 보정.lnk`를 만들며, 상태 파일도 설치 폴더의 `status.json`에 저장합니다. 설치 성공 후 압축을 풀었던 임시 폴더를 옮겨도 보정 실행 경로에는 영향이 없습니다. 원본 ZIP은 다음 복원을 위해 계속 보관하세요.

**이 패키지의 설치 프로그램을 현재 정상 작동 중인 기존 설정 위에 실행할 필요는 없습니다.** 기존 작업 폴더를 가리키는 동일한 이름의 자동 시작 바로가기가 있으면 덮어쓰지 않고 중단합니다. 파일 검증만 하려면 `verify.cmd`를 실행하세요.

## 중지·제거

- 잠시 끄기: 알림 영역의 **한글 입력 임시 보정** 아이콘을 우클릭해 **일시 중지** 또는 **종료**합니다. 다음 실행 때는 다시 활성화됩니다.
- 자동 시작까지 제거: 패키지 또는 `%LOCALAPPDATA%\KoreanInputGuard` 폴더의 **`uninstall.cmd`를 실행**합니다. 이 복원 패키지가 설치한 파일·바로가기만 제거합니다.
- 수동 자동 시작 해제: Win+R → `shell:startup` → `한글 입력 보정` 바로가기를 삭제하고 알림 영역에서 프로그램을 종료합니다.
- 설치 폴더에 직접 넣은 다른 파일이 있으면 제거 프로그램이 그 파일과 폴더를 남깁니다.

## 무엇을 보정하는가

T(ㅅ), O(ㅐ), 한/영 키 해제 후 150ms 이내에 들어오는 ‘다음 곡’ 키 중, 스캔 코드가 0이고 Windows가 소프트웨어 주입(INJECTED)으로 표시한 입력만 차단합니다. 다른 키는 전달합니다. 같은 조건으로 정상 미디어 명령을 만드는 프로그램은 영향을 받을 수 있으며, 그때는 일시 중지할 수 있습니다.

기존 검사에서 T 해제 12번 모두 불필요한 미디어 신호가 관측됐고, O 해제 후에도 같은 신호가 한글 조합을 끝내는 과정이 관측됐습니다. 보정 후 실제 예문 다섯 문장 모두 정상·독립 자모 0개, 불필요한 신호 19회 차단을 확인했습니다. 차단 규칙 자체 검사 25개를 통과했습니다.

추가 신호를 최초 생성한 프로그램·드라이버·장치는 아직 특정하지 못했습니다. 이 보정은 그 신호의 영향을 막는 우회 조치이며, 키보드 고장 여부를 확정하거나 모든 자모 분리 문제를 해결하는 범용 프로그램은 아닙니다. 관리자 권한 앱과 보안 입력 화면에서의 효과는 별도로 검증하지 않았습니다.

보정 프로그램은 전역 키 이벤트를 잠시 검사하고 T/O/한영 해제 시각을 메모리에서 사용합니다. 로컬 상태 파일에는 다음 곡 이벤트 최대 256개, 이 키들과의 시간차, 횟수, PID와 갱신 시각을 기록합니다. 입력 문장·클립보드·일반 키 이력은 저장하거나 전송하지 않습니다. 이벤트가 변하면 약 2초 이내, 변화가 없으면 약 60초마다 상태를 저장합니다.

포함된 `한글입력진단.html`은 브라우저에서 직접 열어 쓸 수 있는 오프라인 검사 페이지입니다. 이 페이지의 검사 입력칸에 직접 입력한 내용과 이벤트만 기록하며, 새로고침하면 지워집니다. 비밀번호 대신 예문만 입력하세요.

## 검증 및 소스

- 실행 파일: `ImeMediaGuard.exe`
- 실행 파일 SHA-256: `7628F7E4D11E6513D57C0C3044EE145A6410A4E31089C504702D397009362D03`
- 소스: `ImeMediaGuard.cs`
- 정책 검사: `policy-tests.json`
- 패키지 검사: `package-verification.json`
- 전체 파일 해시: `SHA256SUMS.txt`

자체 제작 프로그램이며 코드 서명은 되어 있지 않습니다. 보안 경고가 발생하면 보호 기능을 전체 해제하지 말고 이 패키지의 출처·파일 해시와 경고 내용을 확인하세요.

개발 과정에서 한 노트북의 실제 키 입력과 정책을 검증했고, 복원 스크립트는 실제 사용자 시작프로그램을 건드리지 않는 별도 시험 폴더에서 검증했습니다. 새로 설치한 Windows에서의 실행은 아직 시험하지 않았으므로 복원 후 실제 타이핑을 확인해야 합니다.

원본 소스 빌드(컴파일러가 있는 Windows PowerShell, 이 폴더에서):

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /platform:x64 /optimize+ /out:ImeMediaGuard.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll /reference:System.Web.Extensions.dll ImeMediaGuard.cs
```

재빌드한 파일은 해시가 달라질 수 있으므로, 수정·재빌드 배포 시 Setup.ps1의 기준 해시와 패키지 해시도 함께 갱신해야 합니다.
