# 타이핑튠 (TypingTune)

Windows용 한글 입력 진단과 증상별 보정 프로그램입니다. 이전 **Korean IME Media Guard**를 설치형 앱으로 개편했습니다.

**현재 배포 버전: 2.0.4**

- [Windows 설치 파일 다운로드](https://github.com/wasdseok/korean-ime-media-guard/releases/download/v2.0.4/TypingTune-Setup-2.0.4.exe)
- [최신 릴리스 · 소스 ZIP · SHA-256](https://github.com/wasdseok/korean-ime-media-guard/releases/latest)
- [전체 사용 설명](README-ko.md) · [진단 JSON 분석 안내](LLM-JSON-GUIDE.md) · [개인정보와 기록 범위](PRIVACY.md) · [변경 이력](CHANGELOG.md)

## 시작하기

1. 설치 파일을 실행합니다. Windows 10/11과 .NET Framework 4.8 이상이 필요합니다.
2. 바탕화면의 **타이핑튠 (TypingTune)** 아이콘을 더블클릭하면 입력 진단이 열립니다.
3. 팬그램형 문장, 초성·중성·종성, 겹받침, 쌍자음 등의 예문을 직접 입력합니다.
4. **검사 완료 · 다음**을 누르면 진단 JSON이 Windows의 다운로드 폴더에 자동 저장되고 다음 예문으로 넘어갑니다.

다운로드 폴더를 옮긴 경우 Windows에 등록된 실제 위치를 사용합니다. 저장 실패 시 입력과 기록을 유지합니다. **진단 JSON 저장** 버튼으로 저장 위치를 직접 선택할 수도 있습니다.

## 제공 기능

- 두벌식 A–Z 26개와 Shift 조합 7개를 포함하는 예문과 자유 입력
- 초성 19개, 중성 21개, 종성 27개, 겹받침 11개를 검사하는 문장·단어
- 최근 3,000개 진단 이벤트, IME 조합·입력 흐름·보정 상태·수집 상태를 포함한 JSON
- GPT 등 LLM에 전달할 수 있는 자체 설명형 진단 자료와 분석 안내
- 설정 가능한 보정 기준 키와 시간, 알림 영역의 작동 상태·차단 횟수·일시 중지·종료
- 앱 종료·재시작 시 진단 복구 파일 보관

진단과 저장은 로컬에서 수행하며 자동 업로드 기능은 없습니다. 진단 JSON에는 입력한 문장이 포함될 수 있습니다. 사용자 진단·설정·복구 자료는 이 공개 저장소와 배포 파일에 포함하지 않습니다.

## 보정의 적용 범위

새 설치의 보정은 기본으로 꺼져 있습니다. **기존 증상 프리셋**은 특정 노트북에서 관찰한 현상을 바탕으로 한 설정이며 다른 기기에 자동으로 맞춰진 결과는 아닙니다.

보정은 선택한 키 주변에서 나타나는, 주입 표시가 있고 스캔 코드가 0인 **다음 곡** 신호를 제한합니다. 문자 키 자체는 그대로 전달합니다. 개별 물리 키보드를 구분하지 않으며 모든 자모 분리·키 누락·하드웨어 고장을 해결하지 않습니다. 대상 기기에서 같은 예문을 보정 전후로 직접 입력해 비교하세요.

## 빌드와 검증

Windows PowerShell에서 실행합니다. 빌드는 Windows의 .NET Framework C# 컴파일러를 사용합니다.

```powershell
.\build.ps1
.\package.ps1 -CompilerPath 'C:\Tools\Inno Setup 6\ISCC.exe' -SkipBuild
```

설치 프로그램 생성에는 Inno Setup 6.7 이상이 필요합니다. 출력은 `dist/`와 `artifacts/`에 생성됩니다. 빌드에서 코어 58개와 진단 37개, 총 **95개 테스트**를 실행합니다.

2.0.4는 새로 압축을 해제한 소스의 빌드·95개 테스트, 현재 사용자 설치, UI 자동 저장을 확인했습니다. 합성 입력을 이용한 UI 검증은 물리 키보드 오류 개선 검증과 구분합니다. 실행 파일과 설치 파일은 코드 서명되지 않았습니다.

제품 소스와 문서는 현재 브랜치에서 관리하고 설치 파일·소스 ZIP·해시·패키지 명세는 릴리스에 제공합니다. 이전 v1 파일은 현재 브랜치에서 정리했으며 과거 태그와 릴리스에서 확인할 수 있습니다.
